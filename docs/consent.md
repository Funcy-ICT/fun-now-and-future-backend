# 掲載許諾の文言

投稿画面に出す掲載許諾の文言を、版ごとに残す。投稿のドキュメント（`prAssets`）の`consent.version`から、その投稿の人が同意した文言を引くため。全体の構成は[overview.md](overview.md)。

* 今の版は、`src/schema/pr_asset.ts`の`CONSENT_VERSION`
* 文言を変えたら、版も変え、ここに新しい版を足す。前の版は消さない

## 2026-10-draft（仮）

文言はまだ決まっていない。学生に公開する前に、本番の版にする。

本番の文言に入れること:

* 画像の権利を持っていること
* 写っている人の同意を得ていること
* 投稿した人のメールアドレスを、投稿についての連絡先として保存し、消さずに持つこと
