# 0008. 混雑度は (location, 曜日) ごとの基準値に対する比で9段階にする

- ステータス: 一部をADR 0009で置き換え（決定2の一部、決定3、決定4、`max_devices`のスキーマ）
- 決定日: 2026-09-14
- 起票: chirushiyo
- 関連: #23, #1, #11, #25, #28, #32, ADR 0007, ADR 0009

## 背景

当時の`calculateCongestionStatus`は、場所も曜日も見ない固定の閾値（20件未満 = low、50件未満 = medium、それ以上 = high）で判定していた。`GET /getCongestion`と`GET /getCongestionHistory`は、誰も書き込んでいない`sensorData`コレクションを読んでいた。issue #1の「9段階、95パーセンタイル」の方針は未実装のままだった。

## 決定

1. 基準値（`baseline`）は、(location, 曜日) ごとに1つの数値とする
2. 統計量は、稼働時間帯の5分ごとの台数を母集団にした95パーセンタイルとする（→ 母集団の取り方はADR 0009で変更）
3. 参照期間は過去N週間（初期値4）とする（→ ADR 0009で置き換え）
4. levelは`min(9, max(1, ceil(count / baseline × 9)))`で計算する。基準値が無い（`MaxDeviceData | null`が`null`）ときは`level: null`とし、キャリブレーション中として扱う（→ シグネチャはADR 0009で確定）
5. levelは保存せず、読み出すときにサービス層で計算する。`congestion_records`には`uniqueDeviceCount`だけを保存する
6. `GET /getCongestion`系の読み出し先を、`congestion_records`と`max_devices`に切り替える。`windowStart`が15分以上前なら`level: null`、`stale: true`を返す
7. locationの一覧を`config/locations`で管理し、入力の検証（小文字の英数字、`-`、`_`）にも使う（→ 実装では採用しなかった。下記）
8. 基準値は日次のバッチで、毎回全曜日分を計算し直す
9. 平滑化はしない
10. `congestion_records`のドキュメントIDを`${location}__${windowStart}`に固定し、`weekday`（日本時間）を持たせる
11. 既存の`congestion_records`は移行せず、決定10を反映した日から新しく溜める
12. 基準値のバッチができるまでは、`max_devices`をFirestoreのコンソールから手で入れる。`sampleCount: 0`などで手入力だと分かるようにする

## 理由

- 比で定義する: BLEの台数は人数の代わりとしてバイアスを持つ（MACのランダム化、Appleに絞ったこと、Bluetoothをオフにしている人、1人で複数台持つ人）。基準値との比にすれば、場所ごとに一定のバイアスは分子と分母で打ち消される。ただし、時間帯によって端末の構成比が変わるような偏りは残る
- levelを保存しない（決定5）: 式や統計量を後から変えても、過去のデータを計算し直さずに済む
- 実装の順序: 決定10を最優先にした。`weekday`の無い記録は基準値の母集団に入らないので、決定10を反映するまでに溜まったデータは、後からロジックをどう直しても使えない。「取り返しのつかない決定」を先に、「やり直せる決定」を後にする
- staleを15分にする: 集計の窓が5分なので3窓分。窓の確定と書き込みの遅れを差し引くと、実際の余裕は約2窓分
- 「9段階」: issue #1からの前提として引き継いだ。levelを読み出し時に計算するので、内部は9段階のまま、表示では3〜4段階に丸めることも追加のコスト無しでできる

## 結果

- levelは場所をまたいで比べられない。食堂のlevel 7とバス停のlevel 7は、それぞれの容量の7割であって、同じ混み具合ではない
- level 9に張り付く原因は2種類ありうる。ピークが極端に短い場所（パーセンタイルを上げれば緩和できる）と、センサー側の飽和（NimBLEのキャッシュ上限128台で台数が頭打ちになる。パーセンタイルを上げても直らない）。台数の分布が128付近で切れていないかで見分ける
- 決定10を反映した直後は、最大で数週間levelが出せない
- 稼働時間帯の外を「空いている」と表示するか「営業時間外」と表示するかは未定
